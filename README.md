# Arrival Order — an idea for Saccharum's *Unconforming Worlds*

Idea for [poidh #1555](https://poidh.xyz/base/bounty/1555) (open call: https://thebroomsedgetribe.substack.com/p/saccharum-presents-unconforming-worlds).

## Idea (under 100 words)

A poem ordered by how fast each signal actually travels. Stanzas carry rough timestamps. 0.02 s: the fast fibres flinch. 0.3 s: the heart skips and tightens. About 1 s: the slow C-fibres bring the dull ache up from the feet. A few seconds: the gut's vagal report. The mind's sentence comes last, *I'm fine*, and by then every other part has already voted.

> 0.02 s — the shoulder already turning.
> 1.1 s — an ache arriving, late, from the floor.
> 2.4 s — *I'm fine*, says the last to know.

Original work, offered as an idea for the call.
